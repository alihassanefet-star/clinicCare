# 🦷 SmileCare - Dental Clinic Website

A responsive multi-page dental clinic website built using HTML, CSS, JavaScript, and Bootstrap.

## 📌 Project Overview

SmileCare is a front-end web application designed for a dental clinic. It provides patients with information about the clinic, doctors, services, articles, appointments, and contact details.

---

## ✨ Features

- Responsive Design
- Home Page
- About Us Page
- Services Page
- Doctors Page
- Articles Page
- Medical Store Page
- Appointment Page
- Contact Us Page

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Font Awesome
- JSON
- Local Storage
  

---


## 📱 Responsive

The website is responsive and works on:

- Desktop
- Tablet
- Mobile
